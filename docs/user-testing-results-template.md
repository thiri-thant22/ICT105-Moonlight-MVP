## 4. User Feedback Summary

Users found the Budget Tracker Website easy to understand and simple to use. They especially liked the homepage, expense recording feature, and search function. Most users completed the required tasks successfully. Some users suggested adding more expense categories and improving the readability of dashboard charts by using clearer labels.

## 5. Evidence-Based Decision

**Needs minor revision**

The prototype successfully supports the main functions, including viewing the homepage, adding expense records, searching transactions, editing records, and viewing the dashboard summary. Based on user feedback, only minor improvements are needed before the final presentation, such as expanding expense categories and improving dashboard chart labels.
