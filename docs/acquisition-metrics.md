# Acquisition Metrics

## Purpose

Measure early user interest and engagement with the Budget Tracker website by tracking visits, feature usage, and user feedback during the prototype stage.

## Required Metrics

| Metric ID | Metric Name | What It Measures | Formula / Counting Method | Data Source | Target / Success Criterion |
|-----------|-------------|------------------|---------------------------|-------------|----------------------------|
| M-01 | Landing Page Views | Number of users who visited the Budget Tracker homepage | Count homepage visits | Website log / Manual tracking | At least 30 views |
| M-02 | Add Expense Clicks | Number of users who clicked the **Add Expense** button | Add Expense clicks ÷ Landing page views × 100 | Website log | At least 60% click rate |
| M-03 | Budget Tracker Demo | Number of users who tested the Budget Tracker prototype | Count completed prototype sessions | Prototype records | At least 15 users |
| M-04 | Feedback Responses | Number of users who submitted feedback after testing | Count completed feedback forms | Google Form / Survey | At least 10 responses |
| M-05 | Task Completion Rate | Percentage of users who successfully completed the main task (adding an expense) | Completed tasks ÷ Total test users × 100 | Activity log | At least 90% completion rate |

## Interpretation

If the acquisition metrics are lower than the target, the team will:

- Improve the homepage design and content.
- Make the **Add Expense** button more visible.
- Simplify the user interface and navigation.
- Increase prototype testing with more students.
- Improve the explanation of the Budget Tracker's benefits.
