# Demo Script

## Demo Objective
To demonstrate how the Budget Tracker helps users record daily expenses, manage financial records, and monitor their spending through a simple and user-friendly prototype.

## Presenter Roles

| Member | Role in Demo | Part Presented |
| --- | --- | --- |
| Member 1 | Introduction & Landing Page | Introduce the problem, target users, project overview, and demonstrate the Landing Page. |
| Member 2 | Main Workflow | Demonstrate the Try Demo button, Expense Input Form, Record List, Search, and Detail View. |
| Member 3 | Admin & Dashboard | Demonstrate the Admin page, Dashboard summary, project benefits, and conclude the presentation. |

## Demo Flow

| Step | Screen / Feature | What Presenter Says | Requirement ID | Expected User Value |
| --- | --- | --- | --- | --- |
| 1 | Landing/Homepage | Introduce the Budget Tracker, explain the problem of managing daily expenses, and identify the target users. | FR-01 | Users understand the purpose of the system. |
| 2 | Main User Pathway | Click the **Try Demo** button to start the prototype workflow. | FR-02 | Users can easily begin using the system. |
| 3 | Input Form | Demonstrate adding a new expense by entering the amount, category, date, and description. | FR-03, FR-10, FR-11 | Users can quickly record their expenses. |
| 4 | Record List | Display all saved expense records and demonstrate the search/filter feature. | FR-05, FR-06 | Users can easily find and review previous expenses. |
| 5 | Detail View | Open an expense record to display its complete information. | FR-07 | Users can view detailed transaction information. |
| 6 | Status/Admin | Demonstrate editing, deleting, or updating expense records from the admin page. | FR-08, FR-09 | Users can efficiently manage their expense data. |
| 7 | Dashboard/Metrics | Display the dashboard showing total expenses, balance, and spending summary. | FR-12 | Users can quickly understand their financial status. |
| 8 | Closing | Summarize how Budget Tracker simplifies expense management and helps users make better financial decisions. | FR-16 | Users recognize the value of the application. |

## Closing Statement

Thank you for watching our demonstration. Budget Tracker helps users easily record daily expenses, organize financial information, and monitor their spending in one convenient system. Our goal is to make personal budget management simpler, more organized, and more effective for everyone.
