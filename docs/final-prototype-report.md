## 3. Problem Background

Many students and young professionals have difficulty managing their personal finances because they often forget to record daily income and expenses. Existing methods such as notebooks or manual spreadsheets are inconvenient and make it difficult to monitor spending habits. This can lead to overspending and poor financial planning.

---

## 4. Target Users

- Students
- Young professionals
- People who want an easy way to manage personal finances

These users need a simple website that allows them to record income and expenses, search transactions, and monitor their financial status through a dashboard.

---

## 5. Evidence Summary

The project was validated through prototype testing with users.

Main findings:

- Users understood the purpose of the homepage.
- Expense recording was easy to complete.
- Search and filter functions worked effectively.
- Dashboard summaries helped users understand their financial status.
- Users suggested improving mobile responsiveness and validation messages.

---

## 6. Final Prototype Overview

The Budget Tracker Website allows users to:

- Record income
- Record expenses
- Search transactions
- Edit and delete records
- View financial dashboard
- Track remaining balance
- Monitor spending by category

The system stores data locally and provides an easy-to-use interface for personal financial management.

## 8. Data Handling

The system collects and stores:

- Income records
- Expense records
- Categories
- Transaction dates
- Amounts
- Notes (optional)

Data is stored using browser Local Storage. Users can create, update, search, filter, and delete records through the website.

---

## 9. Validation and User Testing Results

Eight users participated in prototype testing.

Results showed that:

- Most users completed all tasks successfully.
- The homepage clearly explained the system.
- Users found adding records easy.
- Dashboard information was useful.
- Search function worked correctly.
- Minor improvements were suggested for mobile responsiveness and validation messages.

Overall decision:

**Needs minor revision before the final presentation.**

## 10. Startup/Product Metrics

The prototype tracks:

- Total Expenses

These metrics help users understand their financial behavior and monitor spending patterns.

## 11. Business Value and Venture Direction

The Budget Tracker Website provides a simple and accessible financial management solution for students and young professionals.

Future improvements may include:

- User accounts
- Cloud database
- Mobile application
- Budget planning
- Spending notifications
- Monthly financial reports

## 12. Limitations and Future Improvements

Current limitations:

- Uses Local Storage only
- No login system
- No cloud synchronization
- Limited reporting features

Future improvements:

- Database integration
- User authentication
- Mobile responsive improvements
- Budget goal tracking
- Data backup
- Export reports to PDF or Excel
