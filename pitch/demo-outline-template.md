# Demo Outline for Final Pitch

## 1. Opening Problem
Many students and young professionals struggle to manage their personal finances because they do not record their income and expenses regularly. This often leads to overspending and poor financial planning.

## 2. Target User
- Primary users: Students
- Secondary users: Young professionals
- Anyone who wants to manage their personal finances more effectively.

## 3. Product Solution
Our **Budget Tracker Website** helps users record income and expenses, organize financial transactions, and monitor their spending through an easy-to-use dashboard.

## 4. Demo Flow
1. Homepage / Landing Page
   - Introduce the Budget Tracker Website.
   - Explain the purpose and value of the system.

2. Main User Action
   - Add a new income or expense transaction.

3. Form Submission
   - Enter transaction details and save the record.

4. Search / Filter / List
   - Search and filter transaction history.

5. Detail / Status
   - View transaction details and financial records.

6. Admin / Update
   - Edit or delete existing transactions.

7. Dashboard / Summary
   - Display total income, total expenses, remaining balance, and spending overview.

## 5. Evidence

### Customer Discovery Evidence
- Students often forget to record daily expenses.
- Many users rely on memory or handwritten notes.
- Users need a simple website to manage personal finances.

### Validation / Testing Evidence
- Most testers successfully completed the main tasks.
- Feedback showed that the system is easy to use but could improve navigation and interface clarity.

### Startup / Product Metrics
- Total Income
- Total Expenses
- Remaining Balance
- Number of Transactions
- Most Used Expense Category

## 6. Closing Value Message
Budget Tracker helps students and young professionals manage their money more effectively by recording daily transactions, tracking expenses, and providing clear financial summaries.
