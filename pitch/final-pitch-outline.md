## Problem and Target Users

### Problem

Many university students and young adults find it difficult to manage daily expenses because they do not keep proper spending records.

### Target Users

- University students
- Young adults
- Personal finance beginners

## Solution and Value Proposition

### Solution

Budget Tracker enables users to:

- Add expenses
- View records
- Search and filter expenses
- View expense details
- Manage records
- Monitor spending through a dashboard

### Value Proposition

A simple and user-friendly system that helps users manage daily expenses and improve financial awareness.
